# 🐍 Snake Water Gun Game

A fun command-line implementation of the classic Snake-Water-Gun game built with Python. Challenge the computer over 10 rounds and see who comes out on top!

---

## 🎮 About the Game

Snake-Water-Gun is a variation of Rock-Paper-Scissors with the following rules:

- 🐍 Snake drinks Water → Snake wins
- 💧 Water drowns Gun → Water wins
- 🔫 Gun kills Snake → Gun wins

The computer makes a random choice each round, and the game keeps track of the scores until all 10 rounds are completed.

---

## ✨ Features

- Interactive terminal gameplay
- Randomized computer moves
- 10-round match system
- Automatic score tracking

- Beginner-friendly Python project

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your system.

### Run the Game

Clone the repository:

bash git clone https://github.com/your-username/snake-water-gun.git 

Navigate to the project directory:

bash cd snake-water-gun 

Run the game:

bash python game.py
